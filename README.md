# Estudio Jurídico Erika

Sitio web profesional para el Estudio Jurídico Erika, desarrollado con HTML, CSS y JavaScript puro.

## Vista General

Este proyecto presenta una landing page institucional moderna, responsive y optimizada para mostrar servicios legales, información profesional, secciones de contacto e interacciones visuales.

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript ES Modules
- IntersectionObserver
- CSS Animations
- Responsive Design

## Cómo Ejecutar Localmente

1. Clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar con Live Server.
4. Abrir `index.html`.

El proyecto no requiere instalación de dependencias ni proceso de build.

## Publicación En GitHub Pages

1. Subir el proyecto a GitHub.
2. Ir a `Settings`.
3. Entrar a `Pages`.
4. Seleccionar la rama `main`.
5. Seleccionar la carpeta `/root`.
6. Guardar los cambios.

## Archivos De Entrada

- `index.html`: estructura principal del sitio.
- `src/css/main.css`: punto único de entrada para estilos.
- `src/js/main.js`: punto único de entrada para JavaScript.
